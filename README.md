# 리듬 구조대

짧은 수리 패턴을 기억하고 순서대로 입력해 고장 난 로봇과 우주선을 구조하는 브라우저 액션 퍼즐 게임입니다.

## 실행

```bash
pnpm install
pnpm dev
```

개발 서버가 안내하는 주소를 브라우저에서 엽니다.

## 조작

- 키보드: 방향키 또는 `W` `A` `S` `D`
- 마우스·터치: 화면의 위·오른쪽·아래·왼쪽 수리 신호 버튼
- 임무 중 브라우저 포커스를 잃으면 자동으로 일시정지됩니다.
- 본부의 `접근성 설정`에서 `소리 사용`과 `진동 사용`, 축소 모션, 시간 목표 완화를 조절할 수 있습니다.
- 소리와 진동을 꺼도 방향 입력과 임무 진행은 그대로 유지되며, 임무 입력 자체를 막지 않습니다.

## MVP 범위

- 본부 → 임무 → 결과 → 본부의 기본 플레이 루프
- 튜토리얼 패턴 미리보기와 네 방향 입력
- 짧은·중간·긴 임무 설정과 다중 수리 지점 진행 (3·5·7개)
- 각 수리 지점 사이의 새 패턴 생성, 임무 전체 콤보·실수·회복 집계
- 마지막 수리 지점을 완료한 뒤 한 번만 지급하는 별·구조 부품 보상
- 성공 입력, 실수·회복, 수리 지점 완료, 임무 완료에 서로 다른 피드백 제공
- 콤보, 실수·회복, 별·구조 부품 보상, 기지 레벨 성장
- 드론·가림·혼합 장애물의 시각 효과
- 축소 모션과 포커스 이탈 일시정지

진행도와 설정은 브라우저의 `localStorage`에만 저장됩니다. 서버 계정, 온라인 기능, 결제, 광고, 외부 분석은 사용하지 않습니다. 저장 키는 `rhythm-rescue-progress-v1`입니다.

## 검증

```bash
pnpm vitest run
pnpm playwright test
pnpm build
```

- 키보드·마우스·터치로 튜토리얼 임무 완료
- 중형 5지점·장거리 7지점 임무가 모든 지점을 거쳐 결과로 이동
- 드론·혼합 장애물 임무 진입
- 소리 끔·축소 모션 설정 저장
- 포커스 이탈 및 `visibilitychange` 일시정지
- 좁은 화면에서 네 방향 버튼 터치

## 프로젝트 구조

- `src/core`: 임무 설정, 패턴, 입력 판정, 진행도
- `src/scenes`: Phaser 씬 수명주기와 화면 전환
- `src/ui`: 접근 가능한 DOM 버튼·설정 패널·장애물 표시
- `src/storage`: localStorage 진행도 저장소
- `tests`: Vitest 단위 테스트와 Playwright 브라우저 테스트

상세 기획과 초기 설계 결정은 [리듬 구조대 설계서](docs/superpowers/specs/2026-08-11-rhythm-rescue-design.md)에서 확인할 수 있습니다.
