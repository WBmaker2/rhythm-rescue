# 리듬 구조대

《리듬 구조대》는 짧은 홀로그램 수리 패턴을 기억하고 순서대로 입력해 고장 난 로봇과 우주선을 구조하는 3D 브라우저 액션 퍼즐 게임입니다.

이번 3D 리디자인에서는 Three.js 기반의 로우폴리 우주 기지, 3인칭 구조대 캐릭터, 수리 목표물, 에너지 레일과 장애물을 조합해 학생들이 게임의 공간과 진행을 한눈에 이해할 수 있도록 구성했습니다.

## 실행

```bash
pnpm install
pnpm dev
```

개발 서버가 안내하는 주소를 브라우저에서 엽니다.

## 플레이 흐름

- 기지에서 `출동 시작`을 누르면 튜토리얼 구조 임무가 시작됩니다.
- `신호 스캔` 단계에서 패턴이 박자에 맞춰 한 칸씩 나타나며, 스캔이 끝난 뒤 패턴을 숨긴 상태에서 위·오른쪽·아래·왼쪽 신호를 순서대로 입력합니다.
- 스캔 중에는 입력 버튼이 잠기고, 올바른 입력은 구조대원 이동·에너지 레일 점등·장애물 반응으로 연결됩니다.
- 인접한 같은 방향이 반복되지 않는 패턴과 `[위] → [위, 오른쪽] → [왼쪽, 아래, 오른쪽]` 튜토리얼로 기억 난이도가 점진적으로 올라갑니다.
- 성공할수록 콤보와 구조 부품이 쌓이고, 수리 지점을 모두 완료하면 기지 레벨이 올라갑니다.
- 기지에서 드론 경계 임무와 혼합 장애물 임무를 선택해 더 복잡한 패턴과 시간 제한에 도전할 수 있습니다.
- 임무 중 브라우저 포커스를 잃으면 자동으로 일시정지됩니다.

## 조작

- 키보드: 방향키 또는 `W` `A` `S` `D`
- 마우스·터치: 화면의 네 방향 수리 신호 버튼
- `Enter` 또는 `Space`: 기지에서 튜토리얼 출동
- `Escape`: 임무 일시정지

단계 진행에 필요한 버튼에는 `gi-pulse` 강조 애니메이션을 적용해 다음 행동을 쉽게 찾을 수 있도록 했습니다. 기지의 작은 `업데이트 내역` 버튼에서는 날짜별 변경 기록을 확인할 수 있습니다.

## 구현 범위

- Three.js WebGL 렌더러와 3인칭 추적 카메라
- 절차적으로 생성하는 로우폴리 기지·구조대·수리 목표물·에너지 레일
- 짧은 3지점·중간 5지점·긴 7지점 구조 임무
- 패턴 미리보기, 콤보, 실수·복구, 시간 제한, 별·구조 부품 보상
- 드론·가림·혼합 장애물의 시각적 움직임과 신호 반응 텔레그래프
- 키보드·마우스·터치 입력과 포커스 이탈 일시정지
- 반응형 저크롬 HUD와 접근성용 축소 모션 토글
- 날짜별 업데이트 내역 패널 및 자동 생성 카탈로그

진행도와 설정은 브라우저 `localStorage`에만 저장됩니다. 저장 키는 `rhythm-rescue-progress-v1`입니다.

## 검증

```bash
pnpm vitest run
pnpm playwright test
pnpm build
```

현재 검증 범위에는 3D 캔버스 생성, 튜토리얼 완료, 키보드 입력, 오입력 복구, 중·장거리 임무 진입, 일시정지·재개, 업데이트 내역, 375x667 좁은 화면 대응이 포함됩니다.

## 프로젝트 구조

- `src/game`: 게임 런타임, 입력 컨트롤러, 미션 콘텐츠, 상태
- `src/render`: Three.js 렌더러·카메라·게임 루프와 3D 오브젝트
- `src/core`: 미션 설정, 패턴 판정, 진행도, 업데이트 기록
- `src/ui`: DOM 기반 HUD, 기지·일시정지·결과 메뉴
- `src/storage`: `localStorage` 진행도 저장소
- `tests`: Vitest 단위 테스트와 Playwright 브라우저 테스트

상세 설계는 [3D 리디자인 설계서](docs/superpowers/specs/2026-08-14-rhythm-rescue-3d-redesign-design.md)에서 확인할 수 있습니다.
구현 단계와 검증 경계는 [3D 리디자인 구현 계획](docs/superpowers/plans/2026-08-14-rhythm-rescue-3d-redesign.md)에 정리되어 있습니다.
이번 플레이 루프 개선 설계는 [게임플레이 개선 설계서](docs/superpowers/specs/2026-08-14-rhythm-rescue-gameplay-revision-design.md), 구현 순서는 [게임플레이 개선 구현 계획](docs/superpowers/plans/2026-08-14-rhythm-rescue-gameplay-revision.md)에서 확인할 수 있습니다.

업데이트 기록은 `src/core/update-history-catalog.json`에 기능 패턴과 날짜를 등록한 뒤 생성 스크립트로 최신 항목을 앞에 추가하는 방식으로 관리합니다.
