# 《리듬 구조대》 플레이 루프 개선 설계

## 문제 정의

현재 임무 화면의 패턴 패널은 중앙에 크게 표시되어 구조대원과 수리 목표물을 가립니다. 모바일에서는 목표 카드·상태 바·패턴 패널·방향 패드가 좁은 화면에 겹칩니다.

게임 규칙도 튜토리얼에서는 한 지점당 단일 방향만 보여주고, 중·장거리 임무에서는 여러 방향을 한 번에 보여준 뒤 같은 버튼을 누르게 합니다. 따라서 플레이어는 패턴을 기억하고 따라간다는 감각보다 정답 아이콘을 보고 입력하는 감각을 받습니다.

## 목표

- 3D 플레이필드의 중앙과 하단 중앙을 정상 플레이 중 비워둔다.
- 패턴을 한 번에 노출하지 않고 박자에 맞춰 순차적으로 스캔한다.
- 패턴을 숨긴 뒤 입력 진행, 성공 피드백, 오답 복구를 명확히 구분한다.
- 튜토리얼도 1개 이상의 방향을 기억하는 단계로 점진적으로 확장한다.
- 정답 입력이 구조대원 이동, 레일 점등, 목표물 수리 전력과 연결되어야 한다.
- 기존 키보드·터치·일시정지·축소 모션 접근성을 유지한다.

## UI 설계

- 좌측 상단: 목표 카드
- 우측 상단: 콤보·부품·일시정지 상태 칩
- 좌측 상단 목표 카드 아래: 폭 280~340px의 소형 패턴 카드
- 중앙: 구조대원, 수리 목표물, 장애물 전용 플레이필드
- 하단 중앙: 방향 입력 패드
- 상태 문구: 패턴 카드 내부의 짧은 상태 문구로 표시해 입력 패드와 겹치지 않게 한다.

패턴 카드는 전체 패턴을 큰 아이콘으로 배치하지 않고 작은 비트 스트립으로 표시한다. 스캔 중에는 현재 방향만 강조하고, 입력 중에는 완료된 비트와 현재 입력 위치만 표시한다.

## 플레이 루프

1. `신호 스캔`: 방향을 한 박자씩 보여주고, 구조대상과 해당 방향 레일을 발광시킨다. 입력은 잠근다.
2. `기억 입력`: 패턴을 숨기고 진행 수만 표시한다. 올바른 입력은 구조대원을 해당 레일로 이동시키고 입력 비트를 잠근다.
3. `오답 복구`: 레일과 패턴 카드가 붉게 흔들리고, 제한된 복구 신호로 같은 패턴을 다시 기억하게 한다.
4. `수리 완료`: 목표물의 전력 링과 눈을 점등하고 콤보·부품 보상을 표시한다.

튜토리얼 패턴은 `[위]`, `[위, 오른쪽]`, `[왼쪽, 아래, 오른쪽]`으로 증가시킨다. 일반 패턴은 인접한 같은 방향을 피하고 임무 길이에 따라 3~6, 5~9, 7~11개 범위를 유지한다. 스캔 시간은 패턴 길이에 비례한다.

## 3D 피드백

- 방향 입력마다 해당 에너지 레일을 짧게 펄스한다.
- 구조대원은 현재 입력 방향의 레일 앵커로 이동한다.
- 수리 지점 완료마다 수리 목표물의 전력값을 올린다.
- 드론과 차단막은 지정 레인을 일시적으로 위협하지만, 시각적 예고 후에만 입력 난이도에 영향을 준다.

## 검증 기준

- 데스크톱 패턴 카드가 중앙 목표물을 덮지 않는다.
- 375x667에서 목표 카드·일시정지·패턴 카드·상태 문구·방향 패드가 겹치지 않는다.
- 튜토리얼에 2개 이상 방향을 기억하는 단계가 존재한다.
- 스캔 중 방향 버튼은 비활성화되고, 스캔 종료 후 활성화된다.
- 잘못된 입력은 복구 상태와 다음 스캔을 표시한다.
- 단위 테스트, 타입검사, 프로덕션 빌드, Playwright 임무 흐름이 통과한다.
